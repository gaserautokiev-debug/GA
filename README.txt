GaserAuto — файли сайту

index.html            — сам сайт
manifest.webmanifest  — дані додатка (назва, іконки, кольори)
sw.js                 — робота без інтернету й встановлення як додаток
icons/                — іконки додатка

Як опублікувати:
1. Завантажте ВСІ файли й папку icons у кореневу папку сайту (на хостингу це зазвичай public_html або www).
   На Netlify: розпакуйте архів і перетягніть папку gaserauto-site у вікно Netlify Drop.
2. Підключіть домен. Сайт має відкриватися за https:// — інакше встановлення як додаток не працюватиме.
3. Відкрийте сайт на телефоні:
   Android (Chrome): угорі сторінки з’явиться кнопка «Встановити додаток» (або меню ⋮ → «Встановити додаток»).
   iPhone (Safari): «Поділитися» → «На екран Додому».

Контакти менеджера змінюються на початку скрипта в index.html, у рядку: var CFG={tg:"GaserAuto",phone:"380731392073"};
